# 项目与会话详情设计

- 创建：2026-09-17；基线 `0.5.3-dev.2`；实施版本 `0.6.0-dev.1`。
- 任务：页面与数据接线。用户要求认真设计后直接修改；本文件为实施依据。
- 核心依赖：开发前已核对远端，最新 tag 为 `v0.2.0-dev.3`；沿用现有解析和计费公式，仅扩展采集查询范围，不分叉核心规则。

## 入口与布局

- 总览「项目概览」和账本「会话归因」右上角增加「查看详情」。项目名、会话 ID 可直接打开对应对象。
- 使用大尺寸详情对话框，保留原页面的位置与筛选；支持关闭按钮、Escape、键盘焦点约束及关闭后焦点恢复。
- 从项目入口继承当前自然或计费周期；未观测 5H 改用近 30 天。从会话模块入口默认近 30 天，直接点击某条会话使用全部本地记录，避免旧会话被短范围隐藏。详情中切换项目 / 会话视图共享同一时间范围。
- 顶部：标题、关闭；下一行：范围快捷选项和自定义日期；再下方为真实边界与本地数据覆盖说明。
- 中部：当前视图筛选结果的 Token、成本和对象数量；搜索、排序、分页。每页 25 项，不截断可查询的总记录数。
- 下部：左侧结果表，右侧对象详情；窄窗口上下排列，各区域独立滚动，表头和关闭操作始终可达。

## 时间与数据

- 支持当前入口周期、近 7 / 30 / 90 天、近一年、全部本地记录及自定义日期。
- 快捷范围按本地自然日包含今天；自定义开始日 00:00 至结束日次日 00:00，事件采用左闭右开区间，未来部分截到采集时间。
- 详情按需扫描 sessions 与 archived_sessions 全部本地 JSONL；主页面维持现有 60 天快速采集，不把历史全量放进常规快照。
- 详情独立使用内存解析缓存，读取现有缓存作初始复用，不写回或驱逐常规采集缓存。全量结果短时复用，刷新可重新检查文件变化。
- 所选范围按 token 事件时间重新聚合，跨日会话不会把范围外 Token 带入。会话创建时间保留作为元数据，另列本范围首末事件。
- 项目归因沿用会话 cwd 到 Git 根目录映射；未识别的会话保留为「未归因」，不静默丢弃。项目 Git 活动单独列示，不能解释为某个会话直接生成的代码。
- Git 使用当前 HEAD 可达提交历史及提交时间查询；新增 / 删除为文本行，二进制不计行数，工作区未提交变化不混入历史范围。读取失败显示未知，不能显示零。
- 「全部」指本机保留的记录，不承诺覆盖被删除记录或云端历史；展示首末可观测事件和扫描文件数。

## 对象详情

- 项目：完整路径、会话数、范围 Token 和成本、Git 提交与增删行、关联会话入口、模型构成、每日用量。
- 会话：完整 ID、归因项目、cwd、创建时间、本范围首末活动、事件数、总 Token、输入 / 缓存输入 / 输出 / 推理输出、模型构成、每日用量。
- 输入总量包含缓存输入，输出包含推理输出，不把分项重复相加；成本继续使用既有已知单价，未知模型明确为未定价。
- 不读取或展示提示词、回复正文、工具命令、凭据；详情不增加外部数据发送或导出入口。

## 交互与状态

- 查询期间显示加载状态；首次全量扫描说明可能耗时。结果带采集时间，重新读取按钮支持刷新。
- 快速切换范围时使用请求序号丢弃过期响应，旧数据不顶替新筛选；错误有重试，空记录有明确空态。
- 日期非法、起点晚于终点或完全在未来时拒绝查询。搜索与排序重置分页，切换范围清理过期对象选择。
- 所选会话在范围内无事件时显示无记录，不把完整会话总量当成本范围数据。

- 页面：独立 ActivityDetails 组件与样式，两个原模块只增加入口。
- 文档：数据契约、UI 合同、组件映射、README、版本与开发记录同步。
- 验证：跨区间会话、精确边界、旧文件、未归因、多模型、Git 失败、非法请求、缓存隔离；完整构建；真实 Electron 入口、日期、搜索、分页、关闭及小窗口检查。
