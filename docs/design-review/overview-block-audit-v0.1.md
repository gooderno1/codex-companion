# 总览页分区设计对照审计（v0.1）

- 创建时间：2026-06-04
- 设计基准：`docs/assets/design/v0.3.3/overview-natural-time.png`
- 实现基准：`v0.2.2-dev.17`
- 本轮目标：按区块对照设计图，避免只凭整页观感修改；同时修正额度卡真实数据口径。

## 1. 左侧导航区

设计要点：

- 产品图标与 `Codex Companion` 标题在同一视觉组内，标题顶线与图标顶线对齐。
- 非官方说明和本机读取状态放在标题下方，不压到标题上方。
- 当前页高亮为浅蓝底，图标为蓝色。
- `设置` 固定在底部。

本轮处理：

- 品牌区已改为图标 + 标题顶线对齐。
- `非官方 Codex 本机仪表盘` 与 `本机读取 · 无上传` 已移到标题下方。
- 当前继续使用本项目非官方自定义图标，不使用 OpenAI / Codex 官方资产。

`v0.2.2-dev.15` 截图差异：

- 当前品牌图标有圆角容器和较多内部留白，截图中视觉尺寸明显小于设计稿。
- 设计稿品牌标识是更大的蓝色几何符号，和 `Codex Companion` 标题组成强品牌组。

验收点：

- 1360x900 与 1080x720 下品牌区不换行错位。
- 设置入口始终可见。
- 品牌图标使用非官方自定义几何标识，视觉尺寸接近设计稿，不使用官方 OpenAI / Codex logo。

## 2. 顶部工具栏

设计要点：

- 页面标题、副标题、时间视角、状态、刷新、快照在同一顶栏内。
- `时间视角 / 自然时间 / 计费时间` 为单行文本切换，不使用外框。
- 顶栏底部只有轻描边。

本轮处理：

- 时间视角已改为单行 flex。
- 配色 token 改为深墨文字、浅蓝描边和更轻阴影。

`v0.2.2-dev.14` 已处理：

- 已移除额外 `桌面总控台` 眉标。
- 页面标题、副标题已改为横向信息组。
- 右侧工作区已改为轻量白底，不再作为强浮层卡片。

验收点：

- 时间视角不能拆成上下两行。
- 右侧快照只出现一次。
- 不显示 `桌面总控台` 眉标。
- `总览` 与副标题同一行展示，顶部工具栏高度接近设计稿。
- 右侧工作区外层只保留轻描边，不使用强阴影和过大圆角。

## 3. 顶部四个指标卡

设计要点：

- 每张卡有大图标、标题、主数字、变化说明和状态标签。
- 大图标位于左侧，标题、主数字和变化说明在右侧形成同一信息组。
- 状态标签位于卡片底部或底部视觉区域，不占用右上角空间。
- 四卡字段固定为 `今日 Token / 本周 Token / 本月 Token / 今日代码改动`。
- 自然时间与计费时间只改变统计口径，不改变卡片结构。

差异与处理：

- 之前实现缺少指标卡大图标。本轮补充 `token / calendar / month / code` 四类自定义 SVG 图标。
- 当前图标采用内联 SVG，不新增外部资产依赖。
- 指标卡已改为“左侧图标 + 右侧内容 + 底部状态标签”。
- 当前实现的指标卡渐变底色和阴影仍比设计稿重，下一步应收敛为接近白底、浅蓝描边和极轻分层。

验收点：

- 四卡图标、标题和主数字层级清楚。
- 主数字只出现一次，不重复展示完整 token。
- 状态标签显示数据源状态，周期口径由顶部时间视角决定，不在每张卡右上重复。

## 4. 5H / 周额度卡

设计要点：

- 标题只显示 `5H 额度窗口` / `周额度窗口`，不再额外显示一行 `额度窗口`。
- 标题可带小图标。
- 圆环中心显示最新剩余百分比。
- 右侧明细展示当前额度周期内的 Token、API 等价成本、代码行数、会话数，每一行应有小图标辅助识别。
- 模型占比展示当前额度周期 Top 3。

本轮数据口径修正：

- `codexCollector` 现在从 `total_token_usage` 累计快照计算真实增量，避免重复累计。
- 无 token 增量但包含 `rate_limits` 的记录也会进入额度观测点。
- `dashboardCollector` 使用 `rate_limits.resets_at + window_minutes` 建立当前 5H / 周额度周期。
- 圆环使用最近一次 `rate_limits` 的真实剩余百分比。
- 右侧 Token、成本、会话数和模型占比使用当前额度周期内的真实增量。

验收点：

- 额度卡不显示重复 `额度窗口` 行。
- 5H 与周额度的 Token / 成本不再只是自然时间窗口估算。
- 若周周期内发生额度重置，周期使用百分比按观测高点累计，剩余量仍以最新 `rate_limits` 为准。
- 额度卡底部展示当前周期 `rate_limits` 观测次数和重置次数，说明数据可信依据。

## 5. 项目概览区

设计要点：

- 项目概览位于底部，独立卡片，表格内部滚动。
- 页级为自然时间时展示 `日 / 周 / 月`。
- 页级为计费时间时展示 `5H / 周额度`。
- 排序项为 `按 Token / 按成本 / 按代码行 / 按最近活动`。

本轮处理：

- 当前布局已保持底部卡片完整露出。
- 计费时间下项目概览的 5H / 周额度边界跟随真实 `rate_limits` 周期。

`v0.2.2-dev.15` 已处理：

- 项目区主标题已改为 `项目概览`，不再使用 `当前周期内的项目消耗与工程活动`。

验收点：

- 页面整体不滚动。
- 只有表格容器允许内部滚动。
- 项目区主标题直接使用 `项目概览`，不再使用“项目消耗”叙述。

## 6. 页脚数据来源区

设计要点：

- 页脚应说明数据来源，而不是只显示价格来源。
- 数据来源说明包含 `Codex 本地 sessions`、`archived_sessions`、`本地 Git`、`不读取云端仓库信息`。
- 右侧或后方以 chip 展示当前 session 文件数、archived 文件数和仓库数量。

本轮差异：

- 当前实现只显示 `OpenAI API Pricing` 和 Codex rate card 定价来源，缺少数据来源 chips。

验收点：

- 页脚包含数据来源说明。
- 页脚展示 `session / archived / 仓库` 三个统计 chip。

## 7. 后续仍需单独确认的细节

- 若后续继续追求像素级接近设计图，需要为每个区块增加固定尺寸标注表。
- 当前图标为代码内 SVG，后续若要形成完整资产包，应迁移到统一 icon registry 或 SVG 文件目录。
- 账本页和代码仓库页应复用本审计格式，不再只做整页截图对照。

## 8. `v0.2.2-dev.14` 结构收敛记录

基于 `v0.2.2-dev.13` 截图与 `v0.3.3` 设计稿，本轮继续处理以下高置信差异：

- 顶部工具栏：已移除 `桌面总控台` 眉标，标题和副标题改为横向组合。
- 外层壳层：已去掉应用外边距和左右间隔，右侧主工作区改为轻量白底，不再使用强浮层阴影。
- 卡片视觉：顶部四卡、中部额度卡和项目概览已统一弱化渐变和阴影，保留浅蓝描边。
- 页脚：继续保留数据来源与定价来源，当前 `1080 x 720` 截图下仍完整可见。

仍需后续关注：

- 当前真实数据只有一个项目时，项目概览表比设计稿更空，这是数据状态差异，不应通过假数据填充。
- 若要进一步贴近设计稿，需要进入区块尺寸标注阶段，逐项约束左侧栏宽度、顶部栏高度、卡片高度、表格行高和底部页脚高度。

## 10. `v0.2.2-dev.16` 品牌标识收敛

基于 `dev.15` 截图与设计稿，本轮处理左侧品牌区的图标形态：

- 图标从“圆角容器内的小型机器人/节点图”改为“更大的蓝色几何 C 形标识”。
- 标识仍为本项目自定义 SVG，不使用 OpenAI、Codex 或其他官方 logo。
- 图标占位从 `52px` 扩大到 `64px`，标题组跟随右移，使品牌区比例更接近设计稿。
- 其余导航项、设置入口和非官方说明不调整。

## 11. `v0.2.2-dev.17` 额度数据证据展示

基于 `dev-ledger` 的额度周期口径，本轮不改变额度数值计算，而是补齐前端可见证据：

- `PeriodMetric` 新增 `quotaEvidence`，暴露周期内 `rate_limits` 观测次数、重置次数、最高已用百分比和最近观测时间。
- `QuotaWindowCard` 底部注记新增 `额度观测 N 次 · 重置 N 次`。
- 圆环仍显示最近一次 `rate_limits` 余量；右侧仍显示当前额度周期 Token、成本、代码行数和会话数。
- 历史重置段明细不在总览页展开，后续更适合放到账本页或额度详情页。

## 12. `v0.2.2-dev.18` 额度注记文案收敛

`dev.17` 截图中额度卡底部已经展示了观测证据，但口径说明仍偏技术化：

- 注记从 `圆环为最近 rate_limits ...` 收敛为 `圆环=最近余量；右侧=当前周期累计。`
- 原始字段、重置段和计算公式保留在数据契约中，不在总览页展开。
- `额度观测 N 次 · 重置 N 次` 保留，用于说明数据可信依据。
