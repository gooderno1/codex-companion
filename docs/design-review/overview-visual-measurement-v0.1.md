- 创建时间：2026-06-04
- 适用版本：`v0.2.2-dev.33`
- 设计基准：`docs/assets/design/v0.3.3/overview-natural-time.png`
- 实现截图：`local_dev_work/overview-1360x900-dev28.png`、`local_dev_work/overview-1080x720-dev28.png`（比例基线），`local_dev_work/overview-1360x900-dev30.png`、`local_dev_work/overview-1080x720-dev30.png`（顶部四卡验证），`local_dev_work/overview-1360x900-dev32.png`、`local_dev_work/overview-1080x720-dev32.png`（左侧导航验证），`local_dev_work/overview-1360x900-dev33.png`、`local_dev_work/overview-1080x720-dev33.png`（项目表格验证）
- 目的：把“对照设计稿还有差距”转成可复用的区块比例验收规则，避免后续页面只靠整页截图主观判断。

## 1. 测量方法

本文件采用轻量人工标注方式：

- 先读取图片实际像素尺寸。
- 再按视觉边界估算主要区块位置。
- 只比较比例和层级，不把 AI 设计图当作像素级切图规范。
- 对真实数据导致的数字长度、模型名长度、项目数量差异不做强行一致要求。

## 4. 当前优先级判断

已达标：

- 左侧边栏宽度和品牌区层级。
- 顶部工具栏单行结构。
- 额度卡高度比例和真实数据说明。
- 小窗口完整显示。

仍可继续精修：

- 顶部四卡高度略低于设计稿，后续可以把 `metric-card` 最小高度和内部间距作为首个微调点。
- 项目概览高度略低于设计稿，但这和真实页脚、定价来源、项目行数有关，不建议为了贴图牺牲数据来源说明。
- 如果用户要求更像设计稿，应先给出具体区块标注，再改 CSS，避免全局拉大间距导致 `1080 x 720` 重新溢出。

## 4.2 顶部四卡内部标注

基于 `overview-natural-time.png` 与 `overview-1360x900-dev28.png` 目测对照：

| 元素 | 设计稿观察 | `dev28` 观察 | 本轮决策 |
| --- | --- | --- | --- |
| 指标图标 | 图标块接近 `42-46px`，视觉权重较强 | 当前为 `42px`，略偏克制 | 小幅增至 `44px`，SVG 从 `24px` 到 `25px`。 |
| 标题 | 粗体清晰，和主数字形成紧凑组 | 当前 `650` 权重略轻 | 提升到 `700`。 |
| 主数字 | 视觉锚点强，数字比标题显著突出 | 当前 `30px`，可读但略保守 | 小幅增至 `31px`，不改单位逻辑。 |
| 变化说明 | 位于主数字下方，色彩表达正负变化 | 当前达标 | 不调整。 |
| 状态标签 | 位于底部视觉区域 | `dev28` 后已进入底部视觉区 | 不再下移，避免挤压小窗口。 |

验收边界：

- 不改四卡字段和统计口径。
- 不增加四卡高度。
- `1080 x 720` 下不得出现数字换行、页脚丢失或页面级溢出。

`v0.2.2-dev.30` 实测结果：

- `1360 x 900`：顶部四卡图标、标题和主数字权重更接近设计稿，卡片高度和区块比例未继续膨胀。
- `1080 x 720`：顶部四卡无数字换行；5H / 周额度、项目概览和底部来源说明仍可见，未出现页面级溢出。
- 本轮只调整视觉权重，不改变自然时间 / 计费时间切换、日 / 周 / 月统计字段、额度窗口字段或项目概览字段。

## 5. 后续页面复用规则

每个页面从设计图进入实际开发时，都必须至少补齐下面 4 项：

- 区块拆分：列出页面的固定区块、数据区块和滚动区块。
- 比例测量：记录设计稿的主要区块宽高比例。
- 实现截图：至少生成 `1360 x 900` 与 `1080 x 720` 两张真实 Electron 截图。
- 差异决策：把差异分为必须修、可接受和因真实数据导致三类。

只有完成这 4 项，才能进入“页面可确认”状态。

## 6. `v0.2.2-dev.28` 顶部四卡局部精修目标

基于第 3 节测量结果，顶部四卡是当前最明确的可修差异：

验收点：

- `1360 x 900` 截图中顶部四卡更接近设计稿舒展比例。
- 状态标签与主数字 / 变化说明之间有更明确的垂直间隔。
- `1080 x 720` 截图仍完整显示左侧导航、顶部工具栏、四卡、额度卡、项目概览和页脚。

验证结果：

- `local_dev_work/overview-1360x900-dev28.png`：顶部四卡更舒展，状态标签与主数字之间的间隔更接近设计稿。
- `local_dev_work/overview-1080x720-dev28.png`：四卡、额度卡、项目概览和页脚仍完整可见，没有出现页面级溢出。
- 后续如果继续追求更高贴合度，应进入更细的卡片内部标注，例如图标尺寸、标题基线和状态标签纵向位置，而不是继续调全局区块高度。
