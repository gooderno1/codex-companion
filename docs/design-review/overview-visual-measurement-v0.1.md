## 1. 测量方法

本文件采用轻量人工标注方式：

- 先读取图片实际像素尺寸。
- 再按视觉边界估算主要区块位置。
- 只比较比例和层级，不把 AI 设计图当作像素级切图规范。
- 对真实数据导致的数字长度、模型名长度、项目数量差异不做强行一致要求。

## 4. 当前优先级判断

已达标：

- 左侧边栏宽度和品牌区层级。
- 顶部工具栏单行结构。
- 额度卡高度比例和真实数据说明。
- 小窗口完整显示。

仍可继续精修：

- 顶部四卡高度略低于设计稿，后续可以把 `metric-card` 最小高度和内部间距作为首个微调点。
- 项目概览高度略低于设计稿，但这和真实页脚、定价来源、项目行数有关，不建议为了贴图牺牲数据来源说明。
- 如果用户要求更像设计稿，应先给出具体区块标注，再改 CSS，避免全局拉大间距导致 `1080 x 720` 重新溢出。

## 4.11 额度周期范围复测

`v0.2.2-dev.44` 聚焦额度卡圆环下方周期范围文案，不调整布局比例：

- 5H 等同日短周期继续显示 `HH:mm - HH:mm`。
- 周额度等多日周期显示 `MM/DD - MM/DD`，避免起止时间相同导致 `周期 09:02 - 09:02` 的误解。
- 该文案仍和重置时间保持同一行，不新增额度卡高度。

验收边界：

- 当前版本截图中，周额度窗口的周期范围不能再只显示两个相同时间点。
- `1080 x 720` 小窗口下，重置与周期文案不能换行，也不能挤压模型占比或底部证据。

## 4.12 目标审计运行态刷新
