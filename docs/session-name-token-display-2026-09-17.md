# 会话名称与 Token 单位显示

- 创建时间：2026-09-17；版本基线：v0.6.1；实施版本：v0.6.2-dev.1。
- 任务类型：本地元数据接线与显示优化；用户明确要求显示 Codex 自动生成的会话名，Token 单位参考总览。
- 数据核查：本机 state SQLite 中 threads.name 的 148 条名称与 session_index.jsonl 的 thread_name 完全一致；threads.title 多数等同首条输入，不能拿来替代自动名称。
- 名称来源：只读最新 state SQLite 的 threads.id / name；缺失、旧 schema 或暂不可读时，按 session_index.jsonl 中 id / thread_name / updated_at 回退，重复记录取最新有效名称。不读 title、first_user_message 或对话正文。
- 元数据更新：查询详情 / 刷新主快照时重新读取名称，与 Token SQLite 索引解耦；改名不必重解析 JSONL 或重建历史索引。
- 页面：账本会话列表、详情列表与对象标题优先显示会话名称；ID 保留为辅助信息及详情完整字段，缺名时使用 ID。详情支持名称和 ID 搜索，并按名称排序。
- 显示：抽出总览已有 formatCompactToken，统一小于 1 万显示整数、1 万起显示万、1 亿起显示亿；精度沿用总览。详情汇总、列表、Token 分项、模型与每日用量统一调用，悬停显示完整数值。
- 单位是自动换算，不改变原始统计、排序与计算；会话数、事件数、Git 行数保持整数，金额保持美元格式。
- 隐私：仅增加名称元数据；主快照可保存名称，历史 Token 索引仍只保存统计数据。不访问云端，不保存原始会话正文。
- 验证：名称优先级、旧 schema、缺失字段、重复 / 损坏索引行、重命名不重解析、单位边界；完整构建、历史详情回归和真实 Electron 列表 / 搜索 / 悬停 / 窄窗口检查。
