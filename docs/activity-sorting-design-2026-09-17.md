# 活动表格双向排序

- 创建时间：2026-09-17；版本基线：v0.6.2-dev.1；实施版本：v0.6.2-dev.2。
- 任务类型：交互调整。用户要求点击 Token 等字段正序 / 倒序，允许完善排序设计。
- 范围：项目 / 会话详情主列表、对象内模型和每日用量表、账本会话归因表。总览项目表已有排序，保留既有实现。
- 表头：可点击字段使用按钮、非活动双箭头、当前升降箭头及高亮，提供 aria-sort 和描述下一步操作的标签；键盘 Enter / Space 可操作。
- 首次点击新字段采用升序，再次点击切为降序，与总览现有操作一致。默认仍按最近活动降序；模型默认 Token 降序，每日用量默认日期降序。
- 主列表支持名称、Token、API 等价成本、会话数 / 用量事件；最近活动继续在排序字段下拉框中选择，旁边增加升序 / 降序切换，表头和工具栏同步。
- 详情的项目 / 会话视图分别保留排序状态；排序只改当前视图。切换排序回到第一页，保留日期、搜索、项目筛选和已选对象。
- 模型表支持模型、Token / 占比、成本；每日表支持日期、Token、成本、事件数。对象切换后恢复对应默认排序。
- 账本会话表支持时间、名称、项目、主模型、Token 和成本；先排序全部已加载会话，再取前 8 条，不能只排序原先的 8 条。
- 比较规则：使用原始数字和时间戳，不按万 / 亿文字或美元显示值；缺失时间始终在后，相同值按稳定 ID / key 排序，不改变统计数据。
- 性能：纯前端排序，无新增 IPC、JSONL 解析、SQLite 或 Git 查询。筛选后排序、排序后分页；汇总值不变。
- 验证：多页数据排序、双向切换、同值稳定、缺失值、名称排序、筛选 / 选中保持、工具栏同步、子表排序、账本先排后截取及无额外数据请求；构建、回归、真实 Electron 和窄窗口检查。
