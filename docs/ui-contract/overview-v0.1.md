# Codex Companion 总览页 UI Contract（v0.1）

- 创建时间：2026-06-03
- 适用版本：`v0.2.2-dev.5` 之后的总览页实现
- 页面来源：`docs/page-design-spec-v0.3.md` 第 2 节
- 状态：进入实际开发前的最终确认稿

## 1. 页面目标

总览页用于快速回答三件事：

- 今天 Codex 用得是否正常
- 当前 `5H` 与 `周额度窗口` 是否紧张
- 当前周期内，哪些项目消耗了更多 Token，并对应了多少代码活动

## 2. 页面结构

总览页由 5 个区域构成：

1. 左侧导航
2. 顶部工具栏
3. 顶部四个指标卡
4. 中部两张额度卡
5. 底部项目概览表

## 2.1 视口约束

实现时至少满足下面两种窗口状态：

- 标准桌面窗口：`1360 x 900`
- 全屏窗口

约束：

- 不依赖全屏才能完整查看页面
- 左侧导航与顶部工具栏不得把主要内容挤出可视区
- 整体页面允许内容区内部滚动，但不能出现整个应用壳层被撑出屏幕

## 3. 左侧导航

固定项：

- 产品图标
- `Codex Companion`
- `非官方 Codex 本机仪表盘`
- `本机读取 · 无上传`
- `总览`
- `Codex 账本`
- `代码仓库`
- `设置`
- 版本号
- `非官方工具`

交互规则：

- `总览` 为当前激活项。
- `设置` 固定在最底部，始终可见。
- 左侧不显示快照时间。

## 4. 顶部工具栏

左侧：

- 页面标题：`总览`
- 页面副标题：`Codex 使用、额度与本地工程活动`

中部：

- `时间视角`
- `自然时间`
- `计费时间`

右侧：

- 数据状态标签：`已观测 / 待刷新 / 未观测 / 数据过期`
- 刷新按钮
- 唯一快照时间：`快照 HH:mm`

交互规则：

- `自然时间 / 计费时间` 为页级切换。
- 页级切换只改变统计口径，不改变页面结构。
- 时间切换使用无边框文本切换。

## 5. 顶部四卡

### 5.1 固定字段

四卡字段在 `自然时间 / 计费时间` 下保持一致：

- `今日 Token`
- `本周 Token`
- `本月 Token`
- `今日代码改动`

### 5.2 展示规则

每张卡片包含：

- 标题
- 主数字
- 次级说明
- 状态标签

约束：

- 主数字只显示一次
- 不重复展示完整 Token 数值
- 不展示会话数、事件数、等价成本
- 不展示趋势曲线

### 5.3 次级说明

默认使用变化说明：

- `较昨日 +12.4%`
- `较上周 +8.7%`
- `较上月 +15.2%`
- `较昨日 -3.1%`

如果某项当前无法提供稳定变化值，可降级为：

- `数据待补齐`
- `未观测`

### 5.4 单位规则

Token 数字自动单位：

- `< 10,000`：整数
- `>= 10,000 && < 100,000,000`：`万`
- `>= 100,000,000`：`亿`

代码改动：

- 使用 `行`

### 5.5 口径规则

`自然时间`：

- `今日 Token`：自然日
- `本周 Token`：自然周
- `本月 Token`：自然月
- `今日代码改动`：自然日

`计费时间`：

- `今日 Token`：当前日
- `本周 Token`：当前周额度窗口
- `本月 Token`：当前计费月窗口；若当前版本还没有稳定月窗口数据，则保持字段不变，但状态显示 `未观测` 或 `待补齐`
- `今日代码改动`：当前日

## 6. 中部两张额度卡

### 6.1 固定字段

中部固定两张卡：

- `5H 额度窗口`
- `周额度窗口`

### 6.2 每张卡结构

左半区：

- 环形进度
- 中心主数字：剩余百分比
- 下方文案：重置时间

右半区：

- `Token 用量`
- `API 等价成本`
- `代码行数`
- `会话数`
- `观测时间`
- `来源状态`

底部：

- Top 3 模型占比条
- 边界注记

### 6.3 边界规则

当前卡片中心数字统一显示：

- `剩余百分比`

不显示：

- 剩余 Token
- 预计可用时长

固定注记：

- `无剩余 Token 原始字段，圆环中心显示剩余百分比。`

## 7. 项目概览

### 7.1 结构

区域标题：

- `项目概览`

能力：

- 可滚动
- 默认按 Token 降序
- 支持排序切换

### 7.2 排序项

- `按 Token`
- `按成本`
- `按代码行`
- `按最近活动`

### 7.3 二级周期切换

当页级视角为 `自然时间`：

- `日`
- `周`
- `月`

当页级视角为 `计费时间`：

- `5H`
- `周额度`

### 7.4 表格字段

- `项目`
- `Token`
- `API 等价成本`
- `代码行数`
- `提交`
- `会话`
- `最近活动`

## 8. 状态与降级规则

如果当前数据源不足，页面按以下优先级降级：

1. 保留字段结构
2. 主数字改为 `未观测` 或 `--`
3. 次级说明改为 `数据待补齐`
4. 状态标签改为 `未观测 / 待刷新 / 数据过期`

禁止：

- 因为缺字段而直接替换四卡字段
- 因为缺月窗口数据而把 `本月 Token` 换成完全不同的指标

## 9. 不实现项

当前总览页不实现：

- 四卡内趋势曲线
- 四卡内会话数 / 事件数 / 成本辅助信息
- 中部卡片的剩余 Token
- 中部卡片的预计可用时长
- 项目表中的主模型列
