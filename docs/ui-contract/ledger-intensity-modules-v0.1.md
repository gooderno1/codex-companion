# Codex 账本页强度模块设计合同（v0.1）

- 创建时间：2026-06-04
- 页面范围：`Codex 账本` 第一行 `Token 走势拆解`、`周期洞察`，以及第二行右侧 `模型贡献`
- 对应版本基线：`v0.2.2-dev.69`
- 当前状态：细化确认稿，优先于示意图阅读

## 1. 模块边界

这份合同只约束下面三个模块：

- `Token 走势拆解`
- `周期洞察`
- `模型贡献`

不受它影响的模块：

- `周额度账本`
- `会话归因`

## 2. 周期状态

这三个模块不再共用同一套周期语义。

### 2.1 Token 走势拆解

`Token 走势拆解` 的数据合同保留 `日 / 周 / 月`，当前产品实现开放三种粒度。

它回答的是“最近走势怎么变化”，所以必须保留较高时间分辨率：

- `日`：当前自然日 `00:00` 到快照时刻
- `周`：最近 `7` 个自然日
- `月`：最近 `30` 个自然日

当前 UI 状态：

- `日 / 周 / 月` 都可用，默认状态为 `周`。
- 主图采用多曲线图，不再使用柱图或额外横轴 / 纵轴下拉控件。
- 曲线图例本身就是显隐控制，用户点击某个图例即可显示或隐藏对应曲线。
- 当前粒度表默认隐藏，避免未放大状态下挤压趋势图。
- 点击某个曲线点位后，右侧滑出当前粒度表；卡片头部 `明细 / 隐藏` 控制也可手动展开或收起。
- 当前视觉实现已把折线改为平滑曲线；曲线必须穿过真实点位，不得为了平滑改变点位数值。
- 当前交互实现已增加 `放大` 入口，用户可以在全截面视图中查看趋势图和当前粒度表。

横轴规则：

- `日`：固定 `小时`
- `周`：固定 `日期`
- `月`：固定 `日期`

交互规则：

- 若当前时间范围只有一种横轴，隐藏横轴切换控件；当前实现三种粒度都只有一种横轴。
- 默认状态为 `周`。
- 主图默认选中 `总 Token` 最高的点位，但当前粒度表默认不展开。
- 用户选择任一点位后，当前粒度表自动展开并同步更新。
- 当前粒度表标题随粒度变化：`日` 为当前小时，`周 / 月` 为当前日期。

### 2.2 周期洞察

`周期洞察` 不再跟随 `日 / 周 / 月`，改用 `近7天 / 近30天 / 累计`。

原因：

- `日` 视角会让右侧摘要过碎，和图表 hover 的信息层级重复。
- `周 / 月` 如果直接显示为两个字，容易被误解成自然周 / 自然月，而这里实际是滚动窗口。
- `全部` 边界不清，不知道是全部分页、全部会话，还是全部观测期。

定义：

- `近7天`：最近 `7` 个自然日
- `近30天`：最近 `30` 个自然日
- `累计`：从本地首个可观测 `CodexTokenEvent` 到当前快照时刻

命名规则：

- 文档与合同统一写 `累计`。
- 如果后续视觉稿里想强调“这是一个时间范围”，可以把按钮文案替换成 `全周期`，但数据口径不变。
- 不使用 `全部`。

默认状态：

- 默认 `近7天`

### 2.3 模型贡献

`模型贡献` 也不再跟随 `日 / 周 / 月`，改用 `近7天 / 近30天 / 累计`。

原因：

- 模型分布比趋势图更适合看一段时间内的聚合结果。
- `日` 粒度过短，模型构成极易抖动，不利于稳定阅读。

定义与命名规则完全跟 `周期洞察` 一致。

默认状态：

- 默认 `近7天`

## 3. Token 关系

当前设计必须遵守下面的关系：

- `总 Token = 输入总量 + 输出`
- `输入总量 = 原始输入 + 缓存输入`
- `缓存输入占比 = 缓存输入 / 输入总量`
- `推理 Token <= 输出`

重要约束：

- `input` 在当前采集口径下应视为 `输入总量`。
- `cachedInput` 是 `input` 的子集，不可与 `input` 再次并列相加。
- `reasoningOutput` 是 `output` 的子集，不可作为与 `output` 并列的独立总量段。

前端推导字段：

- `原始输入 = max(0, input - cachedInput)`

## 4. 曲线定义与可见字段

主图使用多曲线，而不是把 6 个字段做成纵轴下拉切换。当前曲线包括：

- `总 Token`：默认可见
- `输入总量`：默认可见
- `原始输入`：默认隐藏，可通过图例打开
- `缓存输入`：默认可见
- `输出`：默认可见
- `推理 Token`：默认隐藏，可通过图例打开

当前粒度表和 tooltip 必须展示全部 6 条曲线对应数值，不受曲线显隐状态影响。

配色要求：

- 六条曲线必须使用明显不同的色相，避免全部落在相近蓝绿区间。
- 当前实现使用：`总 Token` 蓝、`输入总量` 紫、`原始输入` 橙、`缓存输入` 青、`输出` 绿、`推理 Token` 玫红。
- 图例圆点、曲线路径、点位圆点和当前粒度表色标必须使用同一套颜色。

命名要求：

- 不要只写 `输入`，必须写 `输入总量`。
- `缓存输入占比` 必须明确分母是 `输入总量`。

## 5. 图表形态

### 5.1 主图

- 主图使用 SVG 多曲线图，横向表达时间粒度，纵向表达 token 数。
- 多条曲线共享同一左侧纵轴，纵轴上限来自当前可见曲线的最大值。
- 隐藏曲线只影响可见曲线和纵轴缩放，不改变底层统计。
- 至少保留一条曲线可见，避免空图。
- 曲线形态使用平滑曲线，不再使用直接折线连接。
- 推荐实现为单调三次插值或 Catmull-Rom 到 cubic Bezier 的 SVG `path`；必须避免明显过冲。
- 若任意相邻两点之间的平滑曲线会超过当前两点和相邻点共同形成的局部取值范围，应降级为较保守的二次曲线或直线段。
- 点位圆点必须保留，hover / click 命中区以真实点位为准，不能以平滑曲线上的虚拟位置作为数据点。

### 5.1.1 平滑曲线视觉规则

- 曲线仍表达离散桶数据，不表达桶内连续真实采样。
- 曲线需要穿过每个真实桶点，不能只做近似趋势线。
- `日` 粒度如果有效点少于 `3` 个，可使用直线或轻微二次曲线，不强行平滑。
- `周` 粒度默认 `7` 个日期点，允许平滑，但曲率要克制，不能出现波峰 / 波谷超过真实相邻点过多的视觉误导。
- `月` 粒度点位较多，曲线点和标签需要降密显示；命中区仍覆盖每个日期桶。
- 隐藏某条曲线后，其平滑路径、点位和 hit zone 的视觉反馈一起隐藏；当前粒度表仍保留该字段数值。

### 5.2 当前粒度表

- 默认隐藏；点击点位、横轴日期或 `明细` 控制后展示当前小时或日期的明细。
- 展开后可通过 `隐藏` 控制收起。
- 表格列为 `曲线 / 数值 / 占比`。
- 占比分母为当前点位 `总 Token`。
- 明细区额外展示 `会话 / API 等价成本`；放大态摘要可继续展示 `缓存输入占比`。
- 当前小时或日期标题不重复显示完整日期范围；非放大态只把 `会话 / API 等价成本` 放到日期右侧，避免明细栏横向拥挤。
- `推理 Token` 仍是 `输出` 子集，不得作为与输出并列相加的总量。

### 5.3 放大全截面视图

触发入口：

- `Token 走势拆解` 卡片头部右侧增加一个图标按钮，文案 / tooltip 为 `放大查看`。
- 图标建议使用通用 `Maximize2` 或等价放大图标，不使用文字按钮占用横向空间。
- 入口只影响该模块，不进入页面顶栏，不作为整页视图状态。

展示形态：

- 点击后打开覆盖当前主内容区的模态层或抽屉式全截面面板。
- 左侧导航栏和顶部应用壳层保持可见或弱化遮罩；放大层只覆盖主内容工作区，不伪装成新页面。
- 放大层标题保持 `Token 走势拆解`，右上角提供关闭按钮。
- 放大层内保留与原卡片一致的 `日 / 周 / 月`、曲线图例显隐状态、当前选中点位和明细显隐状态。

布局：

- 上方工具行：标题、粒度切换、曲线图例、关闭按钮。
- 主体：默认由大尺寸平滑曲线图占满。
- 展开明细时：上方展示当前粒度表，下方展示大尺寸平滑曲线图，当前粒度表不遮挡曲线；表格必须保留 `曲线 / 数值 / 占比` 三列。
- 展开明细时：日期、`会话 / API 等价成本 / 缓存输入占比` 摘要和右侧三列表格需要在同一视觉高度内对齐；放大态表格字号、行距和内边距必须明显高于压缩侧栏态。
- 底部可选：显示当前时间范围、可见曲线数量和数据来源状态，不新增无法验证的统计。

交互：

- 在放大层内切换 `日 / 周 / 月` 后，原卡片同步该粒度。
- 在放大层内显示 / 隐藏曲线后，原卡片同步曲线显隐状态。
- 在放大层内点击点位或横轴日期后，原卡片同步选中点位并展开明细。
- 在放大层内展开或隐藏当前粒度表后，原卡片同步明细显隐状态。
- 关闭放大层后保留用户当前选择，不回到默认状态。
- 支持 `Esc` 关闭；点击遮罩关闭可以保留，但不能误触发曲线点位。

边界：

- 放大层不新建独立统计口径，不读取新的数据源，只复用 `snapshot.ledger.trend`。
- 放大层不展示原始对话内容、工作目录全路径或其他隐私字段。
- 如果当前无可观测数据，放大层显示空状态和数据来源说明，不展示假曲线。

## 6. 纵轴与刻度

- 默认只显示左侧纵轴，单位为当前可见曲线的 token 数。
- 右侧纵轴不显示，不允许表达第二单位。

刻度规则：

- 绝对量按当前窗口最大值自动取友好刻度，例如：
  - `5000万`
  - `1亿`
  - `1.5亿`

## 7. Hover 与 Tooltip

悬停或点击任一点位时，tooltip / 当前粒度表必须统一展开：

- 完整时间范围
- `总 Token`
- `输入总量`
- `原始输入`
- `缓存输入`
- `缓存输入占比`
- `输出`
- `推理 Token`
- `会话数`
- `API 等价成本`

补充规则：

- `缓存输入占比` 在 tooltip 中同时给出绝对 token 值，避免只剩百分比。

## 8. 周期洞察

`周期洞察` 只跟随自己的 `近7天 / 近30天 / 累计` 状态变化，不跟随 `Token 走势拆解` 的 `日 / 周 / 月`，也不跟随左侧选中日期。

固定 6 张卡：

- `窗口累计`
- `窗口均值`
- `峰值位置`
- `峰值用量`
- `单次峰值`
- `缓存输入占比`

### 8.1 计算规则

- `窗口累计`
  - 当前周期内 `Σtotal`
- `窗口均值`
  - `近7天`：最近 `7` 日平均每日 `total`
  - `近30天`：最近 `30` 日平均每日 `total`
  - `累计`：观测期平均每日 `total`
- `峰值位置`
  - `近7天`：Token 最高的日期
  - `近30天`：Token 最高的日期
  - `累计`：观测期内 Token 最高的日期
- `峰值用量`
  - 与 `峰值位置` 对应日期的 `total`
- `单次峰值`
  - 当前周期内单个会话 `total` 最大值
- `缓存输入占比`
  - 当前周期内 `ΣcachedInput / Σinput`

### 8.2 文案规则

- `窗口均值` 的副标题动态变化：
  - `近7天`：`7 日日均 Token`
  - `近30天`：`30 日日均 Token`
  - `累计`：`观测期日均 Token`
- `峰值位置` 的副标题不要再写成固定的 `峰值时段`。
- `累计` 视角下不要出现“全部”字样。

## 9. 模型贡献

`模型贡献` 跟随自己的 `近7天 / 近30天 / 累计` 状态，但不跟随 `Token 走势拆解` 的趋势曲线或选中点位。

当前默认：

- 周期：`近7天`
- 默认排序：`Token` 绝对值倒序

交互规则：

- 不使用单独排序按钮。
- 采用点击列表头排序：
  - 初始状态：`Token` 倒序
  - 第一次点击任一字段：按该字段正序
  - 第二次点击同一字段：按该字段倒序
  - 切换到另一字段时重新从正序开始
- 当前页通用排序交互都优先使用“点表头切换排序”，而不是额外一排按钮。

允许排序列：

- `Token`
- `API 等价成本`
- `事件数`
- `占比`

说明：

- 你这轮提到的“默认最新提交，点表头正序 / 倒序”属于同一交互模式，但默认 `最新提交` 只适用于仓库表，不适用于第二页模型贡献。

## 10. 本轮定稿建议

建议直接定成下面这套用户可见命名：

- `Token 构成与强度` -> `Token 走势拆解`
- `强度摘要` -> `周期洞察`
- `模型构成` -> `模型贡献`

周期建议直接定成下面这两套：

- 趋势图：`日 / 周 / 月`
- 右侧两个模块：`近7天 / 近30天 / 累计`
