- 创建时间：2026-06-04
- 页面来源：`docs/page-design-spec-v0.3.md` 第 3 节
- 对应版本基线：`v0.2.2-dev.75`
- 当前状态：已按 `v0.3.15` 设计图落地到数据合同、采集器与渲染层；后续实现变更必须继续保持本文档一致
- 模块级细化补充：`docs/ui-contract/ledger-intensity-modules-v0.1.md`

## 1. 页面目标

账本页不是总览页的复制品，而是回答 `Token 走势拆解`、`周期细账`、`模型贡献` 和 `会话归因` 的页面。

首屏必须优先回答：

- 最近 Token 走势是怎样变化的？
- 最近 `7` 天、`30` 天和累计观察期有哪些关键强度信号？
- 最近几周计费周期的累计投入强度和 API 等价价值是什么？
- 主要消耗来自哪些真实模型？
- 最近哪些会话被归因到项目或仓库？

## 3. 页面结构

### 3.1 第一行：Token 走势拆解 + 周期洞察

左侧主卡为 `Token 走势拆解`：

- `日 / 周 / 月` 原本不是整页状态，而是该模块的局部状态；当前实现开放三种粒度。
- 该模块回答走势变化和当前粒度拆解，不承担右侧摘要与模型聚合的全部周期定义。
- 时间范围定义：
  - `日`：当前自然日 `00:00` 到快照时刻
  - `周`：最近 `7` 个自然日
  - `月`：最近 `30` 个自然日
- 当前展示方式改为 `多曲线走势 + 当前粒度表`：
  - 主图使用曲线图表达不同 token 类型随时间变化。
  - `日` 使用小时粒度；`周` 和 `月` 使用日期粒度。
  - 默认显示 `总 Token / 输入总量 / 缓存输入 / 输出`，同时保留 `原始输入 / 推理 Token` 曲线入口。
  - 用户可点击图例显示或隐藏某条曲线；至少保留一条曲线可见。
  - 点击某个点位后，右侧滑出当前粒度表，展示该小时或日期的各类 token 数值、占比、会话数和 API 等价成本。
  - 当前实现中，曲线已经从直线折线升级为平滑曲线；平滑只改变连接方式，不改变真实点位。
  - 当前实现中，卡片头部已有 `放大查看` 图标按钮，用于打开全截面趋势视图。
- 真实 token 关系必须按下面解释：
  - `总 Token = 输入总量 + 输出`
  - `输入总量 = 原始输入 + 缓存输入`
  - `缓存输入占比 = 缓存输入 / 输入总量`
  - `推理 Token <= 输出`
- 前端若要绘制构成图，必须先推导：
  - `原始输入 = max(0, input - cachedInput)`
- 图形规则：
  - 多条曲线共用同一左侧纵轴，纵轴上限来自当前可见曲线最大值。
  - 隐藏某条曲线只影响可见图形和纵轴缩放，不改变底层统计。
  - `原始输入 = max(0, input - cachedInput)` 作为派生曲线展示。
  - `推理 Token` 仍是 `输出` 的子集，不能与 `输出` 相加作为独立总量。
  - 当前粒度表必须展示 `总 Token / 输入总量 / 原始输入 / 缓存输入 / 输出 / 推理 Token`。
  - 平滑曲线必须穿过真实桶点；当点数不足或局部曲率可能误导时，允许降级为保守曲线或直线段。
  - 点位圆点与点击命中区必须保留，当前粒度表始终以真实桶点为准。
- 纵轴规则：
  - 默认只显示左轴，单位为可见曲线的 token 数。
  - 右轴不显示，不表达第二种单位。
- Hover / Tooltip 必须统一展示：
  - 完整时间范围
  - `总 Token`
  - `输入总量`
  - `原始输入`
  - `缓存输入`
  - `缓存输入占比`
  - `输出`
  - `推理 Token`
  - `会话数`
  - `API 等价成本`
- 放大全截面视图：
  - 入口位于 `Token 走势拆解` 卡片头部右侧，使用放大图标和 tooltip `放大查看`。
  - 放大层覆盖主内容工作区，保留应用壳层，不跳转到新页面。
  - 放大层复用同一套 `日 / 周 / 月`、曲线显隐和点位选择状态。
  - 放大层左侧展示大尺寸平滑曲线图，右侧展示当前粒度表。
  - 关闭放大层后保留当前粒度、曲线显隐和选中点位。
  - 放大层只复用 `snapshot.ledger.trend`，不新增数据源或统计口径。

右侧辅卡为 `周期洞察`：

- 不再跟随左侧主图的 `日 / 周 / 月`。
- 右上角单独提供周期切换：
  - `近7天`
  - `近30天`
  - `累计`
- 不使用 `全部`。
- 固定展示 6 个摘要位：
  - `窗口累计`
  - `窗口均值`
  - `峰值位置`
  - `峰值用量`
  - `单次峰值`
  - `缓存输入占比`
- 计算规则：
  - `窗口累计`：当前周期内 `Σtotal`
  - `窗口均值`：
    - `近7天`：最近 `7` 日平均每日 `total`
    - `近30天`：最近 `30` 日平均每日 `total`
    - `累计`：观测期平均每日 `total`
  - `峰值位置`：当前周期内 Token 最高的日期
  - `峰值用量`：与 `峰值位置` 对应日期的 `total`
  - `单次峰值`：当前周期内单个会话 `total` 最大值
  - `缓存输入占比`：当前周期内 `ΣcachedInput / Σinput`
- `单次峰值` 基于单个会话聚合，不展示原始对话内容。

禁止项：

- 再做一排 `5H / 周 / 月额度` 大卡
- `剩余 Token`
- 固定月额度
- 套餐余额或官方价格
- 预计可用时长

### 3.2 第二行：周额度账本 + 模型贡献

左侧为 `周额度账本`：

- 只用日期区间命名周期
- 默认显示 `MM/DD - MM/DD`
- 完整起止时间只在悬停时展示

字段：

- `起止日期`
- `累计已用`
- `Token`
- `API 等价成本`
- `满额周折算`
- `会话`
- `观测 / 重置`

右侧为 `模型贡献`：

- 右上角单独提供周期切换：
  - `近7天`
  - `近30天`
  - `累计`
- 默认 `近7天`
- 默认按 `Token` 倒序
- 点击列头切换排序：
  - 初始状态为 `Token` 倒序
  - 第一次点击任一字段：按当前字段正序
  - 第二次点击同一字段：按当前字段倒序
  - 切换到另一字段时重新从正序开始
- 不单独放排序按钮
- 模型名优先使用真实标签
- 每行包含：模型名、占比条、主值、次级值

### 3.3 第三行：会话归因

字段：

- `最近时间`
- `会话 ID`
- `项目 / 仓库`
- `主模型`
- `Token`
- `API 等价成本`

补充规则：

- 归因失败时显示 `未归因`
- 工作目录全路径只做次级信息或悬停
- 不展示用户、会话状态、平均响应时长
- 不展开原始对话内容

## 4. 数据边界

现有底层已可推导：

- 原始事件时间戳驱动的 `小时 / 日期 / 周段` 聚合桶
- `TokenBreakdown` 驱动的 `总 Token / 输入总量 / 缓存输入 / 缓存输入占比 / 输出 / 推理 Token`
- `窗口累计 / 窗口均值`
- `峰值位置 / 峰值用量`
- `单次峰值`
- 真实模型聚合
- 会话聚合归因

本轮已接线：

- `DashboardSnapshot.ledger.weeklyPeriods` 提供最近多周计费周期数组。
- 周周期 `累计已用` 来自 `period.quotaEvidence.usedPercent`。
- `满额周 API 等价折算` 在渲染层由 `apiCostUsd / (usedPercent / 100)` 推导，只作为 API 等价估计，不是官方套餐定价。
- `DashboardSnapshot.ledger.trend` 提供 `日 / 周 / 月` 趋势桶；当前渲染层已开放 `日 / 周 / 月` 曲线视图。
- `DashboardSnapshot.ledger.analysis` 提供 `近7天 / 近30天 / 累计` 的周期洞察与模型贡献数据。

当前不应进入设计或实现：

- 顶部重复额度三卡
- `剩余 Token`
- 固定月额度
- 月度计费窗口伪数据
- 假模型名
- 假用户或假状态

## 5. 关键状态

- `已观测`：当前字段可稳定显示。
- `待刷新`：页面可用，但需要等后台采集刷新。
- `未观测`：字段结构保留，但没有可验证数据。
- `数据过期`：当前快照可读，但时效不足。

## 6. 设计验收

本页设计图通过时，至少满足：

- 一眼能看出它和第一页是同一个已落地产品，而不是另一套壳层。
- 首屏主叙事已经从额度三卡转向 `Token 走势拆解 + 周期洞察`。
- `Token 走势拆解` 的数据合同和页面状态都支持 `日 / 周 / 月`；`周期洞察` 和 `模型贡献` 不再硬跟它共用同一套周期。
- 右侧两个模块使用 `近7天 / 近30天 / 累计`，不使用 `全部`。
- token 关系已经讲清：`输入总量`、`缓存输入`、`输出`、`推理 Token` 之间不再互相重复计数。
- `Token 走势拆解` 的多曲线、图例显隐和当前粒度表层级清楚，不依赖额外解释文字补逻辑。
- 平滑曲线不造成数值误导：真实点位、tooltip 和当前粒度表仍以桶数据为准。
- 放大全截面视图只放大图表阅读空间，不改变页面数据口径或隐私边界。
- 不再出现伪字段或旧稿的假模型名。
- 周期账本默认按日期区间阅读，不依赖相对周命名。
- 会话归因保持数据克制，不突破本地隐私边界。
